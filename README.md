# AST-Android

AST 手机版：实时双语同声传译，基于火山同声传译 2.0（AST v2，s2t，只出文字字幕）。

- 手机麦克风录音，16kHz 单声道，80ms 一包发给火山。
- 语言对：中英混 Mixed（zhen 单会话）、中英双向、中日、中韩、中俄、中意、中西、中法、中德双向（两条单向通道、按文字判方向，本地逻辑，非官方方法）。
- 密钥不在仓库里：打开 App，在里面填你自己的火山 API Key，只存在手机本地。
- 翻译需要联网，断网不能翻译。手机版 v1，未经真机实测，装好后请自己实测：填密钥、选语言对、点开始、说中文和英文，看字幕是否实时出来。

## 编译

GitHub Actions 会在 push 到 main 后自动编出 debug APK，见 Actions 的 AST-Android-debug 产物。
